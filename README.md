# FinModel

A curated hub for financial AI research and resources, maintained by [@merthmagic](https://github.com/merthmagic).

## What's in this repo

| Category | Description |
|---|---|
| 📰 **Information Sources** | Curated links and references to key financial data sources, papers, and news feeds |
| 🔬 **Research** | Personal research notes, experiments, and findings in quantitative finance and financial ML |
| 🛠️ **Tools** | Utility scripts and toolkits for financial data processing and model development |
| 📊 **Datasets** | Cleaned and preprocessed financial datasets ready for modeling |
| 🤖 **Models** | Trained models, model cards, and evaluation results |

## Getting Started

Browse the directories above for the content you are interested in. Each subdirectory contains its own `README` with usage instructions.
